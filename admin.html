🛠️ Admin — Update Skema Incentive

Upload file Excel skema incentive mingguan (format sheet "Incentive Schema", "Threshold", "Target Agent"), lalu download schema.json hasilnya untuk di-upload ke folder data/ di repo GitHub.

← Kembali ke Kalkulator Agent

1. Upload File Excel

Sheet wajib: Incentive Schema (kolom Week, STATUS, TEAM, PRODUCT, TH 0..TH n). Opsional: Threshold dan Target Agent.
Hanya baris dengan STATUS ini yang dipakai. Default "Agent".

2. Gabung dengan schema.json yang sudah ada? (opsional)

Kalau dilewati, hasil download hanya berisi minggu dari file Excel yang baru diupload (minggu lama akan hilang kalau langsung menimpa data/schema.json).

3. Preview

4. Download & Upload ke GitHub

Setelah download: buka repo GitHub di browser → masuk folder data/ → klik "Add file" → "Upload files" → pilih file schema.json yang baru di-download ini → pastikan nama file tetap schema.json (menimpa yang lama) → commit. GitHub Pages otomatis update dalam ~1 menit.
